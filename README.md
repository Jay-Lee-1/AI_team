# AI팀 — 앱을 기획·개발·출시·개선하는 작은 AI팀 운영 시스템

Windows PC의 `D:\AI-Team`에서 실행하는 실행 제어 프로그램, 5개 부서 설정, 한국어 관리 화면, 고객 문의 접수 화면입니다.
설치할 추가 라이브러리가 없습니다. Python 표준 기능과 Claude Code CLI만 사용합니다.

```
1 기획·고객 인사이트 → 2 디자인 → 3 개발 → 4 품질 검증 → 5 출시·운영
출시 후: 5 고객 문의 수집 → 1 분석·개선안(최대 3개) → 내가 선택 → 2 → 3 → 4 → 5 업데이트
```

- 실행 프로그램은 계속 켜져서 기다리고, **실행할 일이 있을 때만** 모델을 부릅니다. 할 일이 없으면 토큰을 쓰지 않습니다.
- 내가 선택하지 않은 개선안은 개발하지 않습니다. 24시간 응답이 없어도 승인으로 보지 않습니다.
- 내 답을 기다리는 동안 다른 실행 가능한 일을 우선순위대로 진행합니다.

## 1. 처음 설치 (내가 해야 할 일)

### [내가 해야 할 일] 기본 프로그램 3개 설치
- **할 일:** Git, Python 3, Claude Code 설치
- **지금 필요한 이유:** Git은 변경 전 복구 지점, Python은 실행 프로그램, Claude Code는 실제 모델 호출에 필요합니다
- **공식 사이트:** git-scm.com/download/win · python.org/downloads/windows · code.claude.com/docs (Claude Code 설치 안내)
- **따라 할 순서:**
  1. Git for Windows 설치(기본값 그대로 다음)
  2. Python 3.11 이상 설치. 첫 화면에서 **Add python.exe to PATH** 체크
  3. PowerShell을 열고 Claude Code 공식 설치 명령 실행: `irm https://claude.ai/install.ps1 | iex`
  4. 명령 프롬프트(cmd)를 새로 열고 다음 실행
     ```
     git clone https://github.com/Jay-Lee-1/AI_team D:\AI-Team
     ```
- **비용:** 세 프로그램 모두 무료(확인된 값)
- **완료 후 알려줄 내용:** `doctor.bat` 결과에서 [X] 표시가 있는 줄
- **이 일 때문에 대기하는 작업:** 전체
- **그동안 팀이 진행할 다른 작업:** 없음(설치 전이라 실행되지 않음)

### 환경 확인 (설치·변경 없이 확인만)
`D:\AI-Team\doctor.bat`을 더블클릭합니다. 운영체제, D 드라이브와 여유 공간, Python·Git·Claude Code, 인증 상태, 포트, 인증·예산 설정 여부를 보여줍니다.

관리 화면 상단의 버튼:

- 부서 카드마다 **부서 중지/재개**, 설정 창에서 **프로젝트 일시 중지/재개**가 있습니다.

## 3. Claude 인증과 예산 설정

인증 방식과 하루·월 예산을 정하기 전에는 **실제(유료) 호출을 하지 않습니다**. 모의 데모는 바로 써 볼 수 있습니다.

### 인증 방식 고르기
| 방식 | 언제 | 하는 법 |
|---|---|---|
| **구독 로그인(Pro/Max)** 추천 | 이미 Claude 구독이 있을 때. 사용량이 구독 한도 안에서 처리됩니다 | cmd에서 `claude` 실행 → `/login` → 브라우저에서 로그인 → 관리 화면 설정에서 "구독 로그인" 선택 |
| **API 키** | 사용한 만큼 결제하고 싶을 때 | 아래 '비밀정보 넣는 법'으로 키를 넣고 설정에서 "API 키" 선택 |

### 비밀정보 넣는 법 (채팅·관리 화면에 붙여 넣지 마세요)
1. 시작 메뉴에서 **"계정의 환경 변수 편집"** 검색해서 열기
2. 사용자 변수 → **새로 만들기** → 이름 `ANTHROPIC_API_KEY`, 값에 키 붙여 넣기 → 확인
3. AI팀을 껐다 켜기(`stop-team.bat` → `start-team.bat`)

프로그램은 키 값이 있는지 여부만 확인하고, 값을 코드·로그·화면에 출력하지 않습니다. 로그에 섞여 들어가도 가림 처리합니다.
구독 방식을 고르면 실수로 API 과금이 되지 않도록 호출할 때 API 키 환경 변수를 빼고 실행합니다.

### 예산
관리 화면 → **설정**에서 하루·월 예산(USD), 호출 1회 상한, 선택적으로 하루 토큰 한도를 정합니다.
- 예산의 80%에 가까워지면 핵심 작업(우선순위 1~2)만 진행합니다.
- 상한(안전 여유분 10% 포함)에 닿으면 새 유료 호출을 멈춥니다. 실행 중인 호출은 '집계 중' 예약액으로 미리 계산합니다.
- 호출마다 `--max-budget-usd`로 1회 상한을 걸어 실행합니다.
- 비용 표시는 **CLI가 계산한 추정 API 비용(목록가 기준)** 입니다. 구독 한도 잔여와 실제 청구액은 CLI가 알려주지 않아 **미수집**으로 표시합니다. 실제 청구액은 Anthropic Console 또는 claude.ai 설정에서 확인하세요.

## 4. 처음 쓰는 순서

1. 관리 화면 → **+ 새 프로젝트** → "모의 데모로 만들기" 체크 → 만들기 → **전체 시작**.
   비용 없이 기획 → 디자인 → 개발 → 검증 → 출시 → 문의 → 개선안 선택 흐름을 눈으로 확인할 수 있습니다. 모의 결과는 화면에 **모의**로 표시됩니다.
2. 인증·예산을 설정합니다.
3. 실제 프로젝트를 만듭니다. 앱 이름과 아이디어를 쓰고, 기존 코드가 있으면 폴더 경로를 넣습니다(원본은 그대로 두고 `projects\이름\workspace`에 작업 사본을 만듭니다).
   참고 자료는 `inbox\프로젝트주소이름\`에 .md/.txt로 넣습니다. 자료 속 문장은 지시가 아닌 자료로만 다룹니다.
4. 기획 부서가 방향과 질문(최대 3개)을 올리면 **내가 해야 할 일과 승인 대기**에서 고릅니다.
5. 출시 단계에서 **배포 승인**을 누르기 전까지 운영 배포는 하지 않습니다.

## 5. 부서와 규칙

| 부서 | 하는 일 | 모델 도구 | 쓰기 |
|---|---|---|---|
| 1 기획·고객 인사이트 | 최소 범위·완료 기준, 문의 묶음, 개선안 최대 3개 | 없음 | 없음(결과는 제어 프로그램이 기록) |
| 2 디자인 | 흐름·화면·디자인 체계·로딩/오류/빈 화면, 미리보기 | 없음 | artifacts (제어 프로그램이 기록) |
| 3 개발 | 작은 단위 구현, 테스트 작성, 모의/실제 연결 구분 | 읽기(Read·Glob·Grep), 작업 사본 안만 | 변경안을 제어 프로그램이 경로 검사 후 적용 |
| 4 품질 검증 | 별도 세션에서 완료 기준·디자인·코드 대조 | 읽기, 작업 사본 안만 | 없음 |
| 5 출시·운영 | 검증된 기능만 소개, 사용 안내, 배포·복구 방법, 문의 운영 | 없음 | artifacts |

각 부서의 역할 지침과 입출력 규약은 `departments\0N-이름\role.md`, `config.json`에 있습니다.

### 실행 코드로 적용되는 안전장치
- 모델은 파일을 직접 쓰지 못합니다. 개발 결과는 **변경안(JSON)** 으로 받고, 제어 프로그램이 경로를 검사한 뒤 적용합니다.
- 허용 폴더 밖, `..`, 절대 경로, 링크·junction 경로, `.git`·`.env`, Windows 예약 이름은 차단합니다. 파일 삭제 기능은 없습니다.
- 변경 전 Git 상태를 확인합니다. 사용자가 수정 중인 파일과 겹치면 적용하지 않습니다. 적용 후 작업마다 커밋해 복구 지점을 만듭니다.
- 셸 명령은 실행하지 않습니다. 검증 명령은 허용 목록(`controller\settings.default.json`의 `check_command_allowlist`)에 있는 것만, 셸 없이 실행합니다.
- 같은 작업은 작업 종류·입력·코드 버전으로 중복 생성을 막습니다. 같은 작업 사본은 한 번에 한 작업만 수정합니다.
- 같은 원인 실패는 2회 재시도 후 멈추고 보고합니다. 호출 제한은 1분부터 최대 30분까지 늘려 가며 기다립니다.
- 검증 명령이 실패하거나 테스트가 절반 이하로 줄면 모델 판단과 관계없이 검증 실패입니다. 검증 명령이 하나도 없으면 출시로 넘기지 않습니다.
- 출시 소개에서 검증되지 않은 기능 문구는 자동으로 뺍니다.
- 예산·인증·허용 명령 설정은 `state\settings.json`과 `controller\settings.default.json`에 있고, 모델에게는 이 파일들을 쓸 경로가 없습니다.
- 첨부파일·고객 문의는 `<자료>`로 감싸 자료로만 전달하고, 첨부는 png/jpg/webp/txt만 받으며 실행하지 않습니다.
- 로그는 비밀정보를 가리고 30일 뒤 정리합니다(AI팀 자체 로그만).

### 고객 문의
- 앱에 한 줄을 넣으면 오른쪽 아래에 **문의하기** 버튼이 생깁니다. 웹이 아닌 앱은 `/support` 화면을 앱 안 웹뷰로 엽니다.
  ```html
  <script src="http://127.0.0.1:8790/widget.js" data-project="프로젝트주소이름" data-version="1.0.0" defer></script>
  ```
- 필수: 분류·내용. 선택: 기대 결과·첨부·연락처. 앱 버전·화면·기기 종류만 진단 정보로 함께 받습니다. 가입은 필요 없습니다.
- 같은 고객이 10분 안에 같은 내용을 다시 보내면 새로 접수하지 않습니다. 같은 고객의 다른 문의는 '같은 고객 반복'으로 표시합니다.
- 고객 답변은 초안만 만들고 **자동 전송은 꺼져 있습니다**.
- 고객 서버(8790)는 문의 접수와 본인 접수 상태 확인만 합니다. 관리 서버(8787)는 내 PC에서만 열리고 관리자 토큰이 필요합니다.
- 다른 채널에서 모은 문의는 `inbox\프로젝트\import\*.json`에 넣으면 가져옵니다.

| 예산 도달 | 새 유료 호출을 멈춥니다 | 설정에서 예산을 바꾸거나 다음 날을 기다립니다 |
| 잘못된 변경을 되돌리기 | 작업마다 커밋이 있습니다 | `projects\이름\workspace`에서 `git log`로 확인 후 `git revert 커밋번호`. 강제 초기화는 쓰지 마세요 |
| 상태 DB 손상 | | `stop-team.bat` 후 `state\team.db`를 `backups\`에 복사해 두고 지원을 요청하세요 |

### 자동 시작과 절전 설정
- `autostart-install.bat`: 만들 파일 하나(시작프로그램 폴더의 `AI-Team-start.bat`)와 그 내용을 보여주고, 동의하면 만듭니다. `autostart-remove.bat`으로 지웁니다.
- 절전 설정은 프로그램이 바꾸지 않습니다. 계속 돌리려면 **설정 → 시스템 → 전원 → 화면 및 절전**에서 "전원에 연결된 경우 절전 모드 해제 시간"을 "안 함"으로 직접 바꾸세요.

### C 드라이브에 남는 것
- 프로젝트·작업 사본·결과물·로그·임시 파일·npm/pip 캐시는 모두 `D:\AI-Team` 안에 둡니다(하위 프로세스의 TEMP도 `D:\AI-Team\temp`로 지정).
- Claude Code 자체 설치 파일과 인증 정보는 `C:\Users\사용자\.claude` 등에 남습니다. 인증 저장소이므로 옮기거나 지우지 않습니다. AI팀 호출은 세션 기록을 저장하지 않는 옵션으로 실행합니다. 실제 크기는 `doctor.bat`이 보여줍니다.
- 자동 시작을 켜면 시작프로그램 폴더에 작은 파일 하나가 생깁니다.

## 7. 검증 현황
