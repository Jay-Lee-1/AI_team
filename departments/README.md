# 5개 부서 설정

각 부서 폴더에는 두 파일이 있습니다.

- `role.md`: 모델에게 주는 역할 지침(시스템 프롬프트)
- `config.json`: 입력·출력 규약, 도구 권한, 시간·토큰 한도, 다음 전달 부서

부서 설정은 한 번에 함께 생성되었고, 모델 세션은 그 부서의 작업이 실제로 있을 때만 실행됩니다.
도구 권한과 쓰기 경로 제한은 지침이 아니라 실행 제어 프로그램(controller)의 코드로 적용됩니다.
작업 기록과 사용량 기록은 `state/team.db`의 `tasks`, `events`, `usage` 표에 부서별로 남습니다.
